DeckWright

Present AI-generated HTML slide decks like PowerPoint. Click steps, a presenter view with notes and timer, a pen, and print to PDF, all inside one HTML file. No install, no internet.

Open the demo deck →Press S for the presenter view, ? for shortcuts Open the player →Drop a .hdek package, an .html file or a deck folder GitHub →Install the skill, CLI and spec (MIT)

Use it with Claude

claude plugin marketplace add grotyx/deckwright
claude plugin install deckwright@deckwright

Then ask: “Make my HTML deck presentable” or “Build a 15-minute conference talk as a DeckWright deck.” Other options (npx skills, manual copy, claude.ai upload) are in the README.

What you get

  • Click, wheel, arrow keys and presentation clickers move forward and back, including steps inside a slide. Going back snaps to the previous state without replaying animations.
  • Presenter view on the laptop (current and next slide, notes, elapsed and remaining time) while the projector shows only the slides.
  • Pen, highlighter, laser and eraser on either screen. Pen tablets write right away.
  • Ctrl/⌘+P prints one page per slide with every step revealed.
  • Works on decks that never heard of DeckWright: decks with their own navigation, stacked fixed-size slides and reveal.js are detected automatically.
